# やってる感 PRO（JobSimulator DX）

> 「圧倒的作業中オーラ」をワンクリックで召喚。全リモートワーカーとオフィス戦士に捧ぐ、究極の擬態プラットフォーム。

---

## 📌 概要

PCの前で虚空を見つめる時間、Slackのステータスが「離席中」になる恐怖、突然背後に現れる上司の気配――。
現代のデスクワーカーが直面するあらゆる心理的負荷を、最先端の「擬態テクノロジー」で解決します。

『やってる感 PRO』は、任意のキー連打で超高速タイピングされるハリウッド式コード画面、100万行の神エクセル擬態、無限ビルドコンソール、そしてWebカメラ連動のボス検知センサーにより、あなたに「話しかけづらいほどの猛烈な集中状態」を演出します。

※ 注：本システムをどれだけ稼働させても、実際のタスク進捗は1ミリも進みません。

---

## 🚀 主要機能

### 🖥️ 画面表示系
- **ハリウッド式コード生成**: キーを叩くだけで複雑なコードを超速タイピング。
- **巨大Excel擬態画面**: 100万行・1000列の複雑な関数シートを全画面表示。
- **無限ビルド画面**: 緑色のコンソール文字が永遠に流れ、「今PC重いんで」の免罪符を生成。
- **ボス・センサー（緊急回避）**: Webカメラが背後の人影を検知した瞬間、100ms以内で社内ポータルやニュース画面に切り替え。

### 🔊 サウンド & 擬態系
- **青軸カタカタSE & ターンッ！**: 高級メカニカルキーボードを爆速打鍵する環境音。
- **知的なため息ボイス**: 「うーん、アーキテクチャがな…」と微小音量で呟き、近寄りがたいオーラを強化。
- **マウス・ジグラー**: ポインタを微細に動かし続け、画面ロックや退席ステータスを物理阻止。

### ⚙️ こだわりの仕様
- **あえてファンを回すCPU負荷機能**: PCが頑張っている感を出すため常時CPUを演出消費。
- **定時強制シャットダウン**: 18:01に「残業するな、早く帰れ」と画面をロックする健全機能。
